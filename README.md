# apunts-skill

_Plugin_ de [Claude Code](https://claude.com/claude-code) amb pràctiques d'escriptura
per redactar apunts, exercicis i resums didàctics en valencià amb MkDocs Material.

## Skills

- __`redaccio`__: guia d'estil per redactar, reescriure o revisar apunts.
    Claude l'utilitza automàticament quan es demana redactar o reescriure apunts,
    o es pot invocar amb `/apunts:redaccio`.

## Instal·lació

Des de Claude Code:

```text
/plugin marketplace add joapuiib/apunts-skill
/plugin install apunts@joapuiib
```

## Actualització

```text
/plugin marketplace update joapuiib
```
